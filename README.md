# Disney Adventure-inspired Digital Postcards

Created for Henry-920. Five bilingual Chinese-English digital postcards with original dreamy cruise-inspired backgrounds.

## Files
- `index.html`: collection landing page
- `01.html`–`05.html`: individual postcard pages
- `images/`: five original illustrated backgrounds
- `css/style.css`: responsive styling
- `qr-codes/`: five QR codes pointing to the intended GitHub Pages URLs

## Publish with GitHub Pages
1. Create a **Public** repository named `postcard` at https://github.com/new
2. Extract this ZIP file on your computer.
3. Open the new repository, choose **Add file → Upload files**.
4. Upload the *contents* of this folder (not the outer folder itself), then click **Commit changes**.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch `main` and folder `/(root)`, then click **Save**.
8. Wait for deployment, then open https://henry-920.github.io/postcard/

## Important
The QR codes encode the intended URLs above. They will open correctly after the repository is created and GitHub Pages has successfully published the site. Before printing, test each QR code with a phone after deployment.

The artwork is original cruise-inspired illustration, not official Disney artwork. The public GitHub Pages site can be viewed by anyone with its URL. Google Fonts requires an internet connection; system serif fonts are used as fallback.
