# Five Wishes — Digital Postcards

Five independent bilingual digital postcards inspired by a memorable cruise.

## Pages
- `01.html` — Happiness / 幸福
- `02.html` — Togetherness / 陪伴
- `03.html` — Dreams / 梦想
- `04.html` — Peace & Blessings / 平安
- `05.html` — Cherish the Present / 珍惜当下

Each page opens directly from its own QR code. There is no home page or return button.

## GitHub Pages
Keep the `css`, `images`, and `qr-codes` folders alongside the five HTML files in the repository root. Enable GitHub Pages from the `main` branch and `/ (root)`.

The QR codes point to:
- https://henry-920.github.io/postcard/01.html
- https://henry-920.github.io/postcard/02.html
- https://henry-920.github.io/postcard/03.html
- https://henry-920.github.io/postcard/04.html
- https://henry-920.github.io/postcard/05.html

The artwork is displayed as a real image element at its natural aspect ratio, so it is not cropped or stretched. Text is placed over the open sky area. Check each published link and scan each QR code before printing.
